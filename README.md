# Nusantara Sky Run

A 3D flight game for the make.fun bounty "Make the best flight game" (best-flight-game-20261126-0057), entered as @amiou9.

Fly the red-and-white bush plane **Elang Laut PK-NUS** over the **Kepulauan Elang** island chain: thread **6 golden rings** past the volcano and the lighthouse, watch your fuel — rings top it up — then bring her home for a gentle touchdown on **runway 07 at Pulau Landasan**. Hard landings cost damage, running dry costs the sortie; a fast, clean landing earns a time bonus.

**How to fly:** arrows (or A/D) bank and pitch, W/S throttle, mouse steers, Space air brake, C switches chase/cockpit camera, P pauses, Enter starts again. Runs entirely offline from static files — open `game/index.html` in desktop Chrome, or `node serve.ts` and visit the local page. Three.js 0.187.0 is vendored under `game/vendor/`; sound is synthesised in the browser with WebAudio, no audio files.
